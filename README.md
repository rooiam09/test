# For Priyu ❤️

A private-feeling, static romantic website for Priya.

## Run locally
Open `index.html` in a browser.

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload **everything inside this folder**.
3. Go to **Settings → Pages**.
4. Under "Build and deployment", choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a public Pages URL.

## Optional music
If you want a song:
- Put an MP3 named `our-song.mp3` in the same folder as `index.html`.
- The existing music button will play/pause it.

The photos are already placed in `images/`.
